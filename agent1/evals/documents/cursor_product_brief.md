# Cursor Product Brief - Evaluation Fixture

## Overview
Cursor is represented in this evaluation fixture as an AI-first code editor for professional developers and software teams.

## Features
The fixture describes repository-aware chat, code completion, multi-file editing, agent workflows, and tool-assisted task execution.

## Pricing
The fixture uses individual subscription and team subscription as the commercial model. Exact prices are intentionally omitted.

## Customers
Target users include individual professional developers, startup engineering teams, and organizations evaluating AI-first development workflows.

## Technology
The product combines code models, repository context retrieval, editor integrations, and controlled tool execution.

## Limitations
Evaluation criteria include context accuracy, generated-code review, data governance, predictable cost, and administrator controls.
