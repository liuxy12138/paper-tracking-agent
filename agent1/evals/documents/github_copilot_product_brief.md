# GitHub Copilot Product Brief - Evaluation Fixture

## Overview
GitHub Copilot is represented in this fixture as an AI coding assistant integrated with developer tools and the GitHub ecosystem.

## Features
The fixture covers code completion, chat, IDE assistance, pull-request support, and organization-level policy controls.

## Pricing
The commercial structure includes individual, business, and enterprise-oriented plans. Exact prices are intentionally omitted.

## Customers
Target users range from individual developers to enterprises that prioritize existing IDE workflows and centralized governance.

## Technology
The product combines model inference, IDE context, repository signals, GitHub integration, and policy enforcement.

## Limitations
Buyers should evaluate suggestion quality, repository-context coverage, security review, seat management, and governance requirements.
